# 📊 Обзор источников (my_overview.py)

**Файл:** `bot/handlers/my_overview.py`  
**Версия:** 5.0 (23 февраля 2026)

---

## 📋 Обзор

Обзор всех источников пользователя с краткой статистикой.

**Команда:** `/overview`

---

## 🎯 Команды

### `/overview` — Обзор источников

**Описание:** Показ сводной статистики по источникам.

**Логика:**
1. Получение всех групп пользователя
2. Подсчёт:
   - Количество групп
   - Количество тем
   - Количество источников
   - Активные/неактивные источники
3. Показ статистики

**Клавиатура:** `get_overview_kb()`

---

## 📊 Статистика

### Выводимая информация

```
📊 ОБЗОР ИСТОЧНИКОВ

Группы: 3
Темы: 7
Источники: 12
├─ Telegram: 8
└─ YouTube: 4

Активные: 10
Неактивные: 2
```

---

## 🔁 Callback-запросы

### `overview_refresh` — Обновить

Обновление статистики.

**Логика:**
1. Перезапрос данных из БД
2. Обновление сообщения

---

### `overview_details` — Детали

Переход к детальному просмотру.

**Логика:**
1. Переход к `/list`
2. Показ списка групп

---

### `overview_back` — Назад

Возврат в главное меню.

**Клавиатура:** `get_main_menu_inline()`

---

## 🗂️ Зависимости

| Модуль | Назначение |
|--------|------------|
| `bot.keyboards.get_overview_kb` | Клавиатура обзора |
| `bot.utils.menu_message.update_or_send_menu` | Управление сообщением |
| `core.models.ManagedGroup` | Модель группы |
| `core.models.GroupTopic` | Модель темы |
| `core.models.ContentSource` | Модель источника |
| `core.models.SourceSubscription` | Подписка на источник |

---

## 🗄️ База данных

### Запросы

| Операция | Таблица | Условия |
|----------|---------|---------|
| Получить группы | `managed_groups` | `user_id = ?` |
| Получить темы | `group_topics` | `chat_id IN (?)` |
| Получить источники | `source_subscriptions` | `user_id = ?` |
| Типы источников | `content_sources` | `source_id IN (?)` |
