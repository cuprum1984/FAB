# ⚙️ Настройки (settings_handler.py)

**Файл:** `bot/handlers/settings_handler.py`
**Версия:** 6.6 (2 апреля 2026)

---

## 📋 Обзор

Хендлеры для настроек пользователя: смена языка, стиль иконок, уведомления, **удаление данных (GDPR)**.

**v6.6:** Добавлено полное удаление данных пользователя через кнопку "🗑️ Удалить мои данные".

---

## 🎯 Команды

### `/settings` — Настройки

**Описание:** Открытие меню настроек.

**Логика:**
1. Проверка пользователя в БД
2. Показ меню настроек
3. Переход в состояние `Settings.main`

**Клавиатура:** `get_settings_menu_inline()`

---

## 🔁 Callback-запросы

### `settings_main` — Главное меню настроек

Показ основного меню настроек.

**Клавиатура:** `get_settings_menu_inline()`

---

### `settings_language` — Смена языка

Показ меню выбора языка.

**Клавиатура:** `get_language_menu()`

**Опции:**
- 🇷🇺 Русский
- 🇬🇧 English
- 🇺🇦 Українська
- 🇧🇾 Беларуская

---

### `lang:{code}` — Выбрать язык

Установка языка пользователя.

**Параметры:**
- `code` — код языка (`ru`, `en`, `uk`, `be`)

**Логика:**
1. Обновление `UserPreferences.language`
2. Обновление `TelegramAccount.language_code`
3. Подтверждение смены
4. Возврат в меню настроек

**Текст:** `settings.language_changed`

---

### `settings_icons` — Стиль иконок

Выбор стиля иконок (в разработке).

**Планируемые опции:**
- Классические
- Минималистичные
- Цветные

---

### `settings_notifications` — Уведомления

Настройка уведомлений (в разработке).

**Планируемые опции:**
- Уведомления о новых источниках
- Уведомления об ошибках
- Частота дайджестов

---

### `settings_delete_data` — Удалить данные

Удаление данных пользователя (GDPR).

**Клавиатура:** `get_confirm_delete_kb()`

**Логика:**
1. Подтверждение удаления
2. Каскадное удаление:
   - `UserPreferences`
   - `UserChannelSubscription`
   - `UserCachedMedia`
3. Возврат в главное меню

**Текст:** `settings.data_deleted`

---

### `settings_back` — Назад

Возврат в главное меню.

**Клавиатура:** `get_main_menu_inline()`

---

## 📊 Схема работы

```
/settings
  ↓
[Меню настроек]
  ├─→ Язык → Выбор языка → Сохранение → Назад
  ├─→ Иконки → (в разработке)
  ├─→ Уведомления → (в разработке)
  ├─→ Удалить данные → Подтверждение → Удаление
  └─→ Назад → Главное меню
```

## 🔒 Удаление данных (v6.6)

**Кнопка:** "🗑️ Удалить мои данные"

**Состояние:** `Settings.confirm_delete`

**Хендлеры:**
- `on_settings_delete()` — показ предупреждения
- `confirm_delete_data()` — подтверждение, удаление
- `cancel_delete_data()` — отмена

**Что удаляется:**
1. `UserChannelSubscription` — личные подписки
2. `SourceSubscription` — добавленные подписки
3. `GroupTopic` — созданные темы
4. `ManagedGroup` — группы владельца ← **НОВОЕ (v6.6)**
5. `UserPreferences` — настройки
6. `TelegramAccount` — аккаунт ← **НОВОЕ (v6.6)**
7. Redis — кеш (FLUSHALL)

**Важно:**
- Аккаунт **полностью удаляется**, не помечается
- Главное меню **не отправляется** после удаления
- Последнее сообщение — об успешном удалении
