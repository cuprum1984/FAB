# 🏠 Общие хендлеры (common.py)

**Файл:** `bot/handlers/common.py`  
**Версия:** 3.3 (20 февраля 2026)

---

## 📋 Обзор

Обработчики общих команд: `/start`, `/help`, `/refresh`. Главное меню бота.

---

## 🎯 Команды

### `/start`

**Описание:** Начало работы с ботом.

**Логика:**
1. Проверка пользователя в БД
2. Если новый — регистрация
3. Отправка главного меню

**Тексты:**
- Новый пользователь: `common.start_new`
- Существующий: `common.start_return`

**Клавиатура:** `get_main_menu_inline()`

---

### `/help`

**Описание:** Справка по боту.

**Тексты:** `common.help`

**Клавиатура:** `get_main_menu_inline()` с кнопкой помощи

---

### `/refresh`

**Описание:** Обновление главного меню.

**Логика:**
1. Очистка состояния FSM
2. Перезапуск сообщения меню

---

## 🔁 Callback-запросы

### `menu_add` — Добавить канал

Переход к добавлению источника (`/add`).

### `menu_sources` — Мои источники

Переход к навигации по источникам (`/list`).

### `menu_feed` — Лента

Показ ленты источников.

### `menu_settings` — Настройки

Переход к настройкам (`/settings`).

### `menu_help` — Помощь

Показ справки.

---

## 📊 Схема работы

```
/start
  ↓
[Проверка в БД]
  ├─→ Новый → Регистрация → Главное меню
  └─→ Существующий → Главное меню
  ↓
[Ожидание команды/callback]
```
