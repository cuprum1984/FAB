# 📚 Мои источники (my_sources_interactive.py)

**Файл:** `bot/handlers/my_sources_interactive.py`  
**Версия:** 5.7 (9 марта 2026)

---

## 📋 Обзор

Интерактивная навигация по источникам пользователя: группы → темы → источники.

**Команда:** `/list`

---

## 🎯 Команды

### `/list` — Мои источники

**Описание:** Начало интерактивной навигации по источникам.

**Логика:**
1. Получение групп пользователя
2. Показ списка групп
3. Переход в состояние `MySources.viewing`

**Клавиатура:** `get_groups_inline_kb()`

---

## 🔁 Callback-запросы

### `list_groups` — Показать группы

Показ списка групп пользователя.

**Клавиатура:** `get_groups_inline_kb()`

**Пагинация:**
- 5 групп на странице
- Навигация: `[◀️ .] [1/N] [. ▶️]`

---

### `list_group:{chat_id}` — Выбрать группу

Выбор конкретной группы.

**Параметры:**
- `chat_id` — ID группы

**Логика:**
1. Получение тем группы
2. Показ списка тем
3. Переход в состояние `MySources.selecting_topic`

**Клавиатура:** `get_topics_inline_kb()`

---

### `list_topic:{topic_id}` — Выбрать тему

Выбор конкретной темы.

**Параметры:**
- `topic_id` — ID темы

**Логика:**
1. Получение источников темы
2. Показ списка источников
3. Переход в состояние `MySources.viewing_sources`

**Клавиатура:** `get_source_list_kb()`

---

### `list_source:{source_id}` — Просмотр источника

Просмотр деталей источника.

**Параметры:**
- `source_id` — глобальный ID источника

**Информация:**
- Название источника
- Тип (Telegram/YouTube)
- Статус (активен/неактивен)
- Дата добавления

**Клавиатура:**
- Удалить источник
- Назад к списку

---

### `list_source_delete:{source_id}` — Удалить источник

Удаление источника из темы.

**Параметры:**
- `source_id` — глобальный ID источника

**Логика:**
1. Подтверждение удаления
2. Удаление `SourceSubscription`
3. Удаление `TopicSourceAssignment`
4. Обновление списка

**Текст:** `sources.source_deleted`

---

### `list_back:{target}` — Назад

Возврат к предыдущему экрану.

**Параметры:**
- `target` — целевой экран (`groups`, `topics`, `sources`)

---

### `list_cancel` — Отмена

Выход из навигации.

**Логика:**
1. Очистка состояния FSM
2. Показ главного меню

**Клавиатура:** `get_main_menu_inline()`

---

## 📊 Схема работы

```
/list
  ↓
[Список групп] ←─┐
  ↓              │
[Выбор группы]   │
  ↓              │
[Список тем]  ←──┤
  ↓              │
[Выбор темы]     │
  ↓              │
[Список источников] ←─┤
  ↓              │
[Детали источника]   │
  ├─→ Удалить → Назад
  └─→ Назад ───┘
```

## 🗂️ Зависимости

| Модуль | Назначение |
|--------|------------|
| `bot.keyboards.get_groups_inline_kb` | Список групп |
| `bot.keyboards.get_topics_inline_kb` | Список тем |
| `bot.keyboards.get_source_list_kb` | Список источников |
