# 👥 Выбор группы (group_select_handlers.py)

**Файл:** `bot/handlers/sources/group_select_handlers.py`  
**Версия:** 5.7 (9 марта 2026)

---

## 📋 Обзор

Выбор группы для добавления источника.

---

## 🎯 Обработчики

### Выбор группы (callback handler)

**Состояние:** `AddChannel.choose_group`

**Логика:**
1. Получение списка групп пользователя
2. Показ списка групп
3. Ожидание выбора

**Клавиатура:** `get_groups_inline_kb()`

**Пагинация:** 5 групп на странице

---

## 🔁 Callback-запросы

### `group_select:{chat_id}` — Выбрать группу

**Параметры:**
- `chat_id` — ID группы

**Логика:**
1. Сохранение группы в состоянии
2. Переход к выбору темы
3. Переход в состояние `AddChannel.choose_destination`

---

### `group_add_new` — Добавить новую группу

**Логика:**
1. Переход к инструкции по добавлению группы
2. Показ команды `/activ`

**Текст:**
```
📋 Как добавить группу:

1. Добавьте бота в группу
2. Дайте права администратора
3. Отправьте /activ в группе

[🔙 Назад]
```

---

### `group_back` — Назад

**Логика:**
1. Возврат к предыдущему этапу
2. Очистка выбранной группы
