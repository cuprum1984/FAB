# 📋 Просмотр списка (list_handlers.py)

**Файл:** `bot/handlers/sources/list_handlers.py`  
**Версия:** 5.7 (9 марта 2026)

---

## 📋 Обзор

Просмотр списка источников с возможностью управления.

---

## 🎯 Обработчики

### Просмотр списка (callback handler)

**Состояние:** Любое

**Логика:**
1. Получение списка источников
2. Показ с пагинацией
3. Возможность удаления

**Клавиатура:** `get_source_list_kb()`

**Пагинация:** 5 источников на странице

---

## 🔁 Callback-запросы

### `list_view` — Показать список

**Логика:**
1. Получение источников пользователя
2. Показ списка с пагинацией

---

### `list_delete:{source_id}` — Удалить источник

**Параметры:**
- `source_id` — глобальный ID источника

**Логика:**
1. Подтверждение удаления
2. Удаление `SourceSubscription`
3. Удаление `TopicSourceAssignment`
4. Обновление списка

**Текст:** `sources.source_deleted`

---

### `list_edit:{source_id}` — Редактировать источник

**Параметры:**
- `source_id` — глобальный ID источника

**Логика:**
1. Показ деталей источника
2. Возможность редактирования названия

---

### `list_back` — Назад

**Логика:**
1. Возврат в главное меню

**Клавиатура:** `get_main_menu_inline()`

---

## 🗂️ Зависимости

| Модуль | Назначение |
|--------|------------|
| `core.models.SourceSubscription` | Подписка |
| `core.models.TopicSourceAssignment` | Назначение |
| `bot.keyboards.get_source_list_kb` | Список источников |
| `bot.utils.menu_message.update_or_send_menu` | Управление сообщением |

---

## 🗄️ База данных

### Запросы

| Операция | Таблица | Условия |
|----------|---------|---------|
| Получить источники | `source_subscriptions` + `content_sources` | `user_id = ?` |
| Удалить подписку | `source_subscriptions` | `source_global_id = ?` |
| Удалить назначение | `topic_source_assignments` | `subscription_id = ?` |

---

## ⚠️ Особенности

1. **Пагинация:** 5 источников на странице
2. **Каскадное удаление:** Удаление подписки удаляет назначения
3. **Inline-only:** Только inline-клавиатуры
