# 👨‍💼 Админ-панель (admin.py)

**Файл:** `bot/handlers/admin.py`  
**Версия:** 4.1 (21 февраля 2026)

---

## 📋 Обзор

Хендлеры для админ-панели и управления группами/темами.

---

## 🎯 Команды

### `/activ` — Активация группы

**Описание:** Активация группы для управления ботом.

**Логика:**
1. Проверка типа чата (группа/супергруппа)
2. Проверка прав отправителя (admin/creator)
3. Проверка прав бота (can_post_messages)
4. Сохранение группы в БД (`ManagedGroup`)
5. Отправка подтверждения в ЛС

**Тексты:**
- `admin.activ_not_admin` — не администратор
- `admin.activ_bot_not_admin` — бот не администратор
- `admin.activ_success` — успешно активирована

**Клавиатура:** Нет (ответ в группе без клавиатуры)

---

### `/plus` — Добавить группу

**Описание:** Начало процесса добавления группы.

**Логика:**
1. Проверка прав администратора
2. Переход в состояние `AdminPanel.add_group`
3. Ожидание пересланного сообщения из группы

**FSM:** `AdminPanel.add_group`

---

### `/mytopics` — Мои темы

**Описание:** Просмотр своих тем.

**Логика:**
1. Получение групп пользователя
2. Показ списка групп
3. Навигация по темам

**Клавиатура:** `get_groups_inline_kb()`

---

## 🔁 Callback-запросы

### `admin_panel` — Открыть админ-панель

Показ главного меню админ-панели.

**Клавиатура:** `get_admin_panel_menu_inline()`

---

### `admin_groups` — Управление группами

Показ списка групп для управления.

**Клавиатура:** `get_groups_inline_kb()`

---

### `group_add` — Добавить группу

Начало процесса добавления группы.

**FSM:** `AdminPanel.add_group`

---

### `group_select:{chat_id}` — Выбрать группу

Выбор конкретной группы для управления.

**Параметры:**
- `chat_id` — ID группы

**FSM:** `AdminPanel.group_selected`

---

### `topic_add:{chat_id}` — Добавить тему

Добавление новой темы в группу.

**Параметры:**
- `chat_id` — ID группы

**FSM:** `AdminPanel.waiting_for_topic_name`

---

### `topic_manage:{topic_id}` — Управление темой

Управление существующей темой.

**Параметры:**
- `topic_id` — ID темы

**FSM:** `AdminPanel.topic_selected`

---

### `topic_delete:{topic_id}` — Удалить тему

Удаление темы из группы.

**Параметры:**
- `topic_id` — ID темы

**Клавиатура:** `get_confirm_delete_kb()`

---

## 📊 Схема работы

```
/activ (в группе)
  ↓
[Проверка прав]
  ↓
[Сохранение группы]
  ↓
[Подтверждение в ЛС]

/admin_panel (callback)
  ↓
[Меню админ-панели]
  ├─→ Группы → Список групп → Выбор группы → Управление
  ├─→ Темы → Список тем → Выбор темы → Управление
  └─→ Назад → Главное меню
```
