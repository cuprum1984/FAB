# Лимиты Free плана — Контекст

**Последнее обновление:** 2026-03-31
**Версия:** 6.4
**Статус:** ✅ Реализовано (v6.4)

---

## 📋 Что это

Защита от злоупотреблений в бесплатной версии бота. Ограничивает количество ресурсов на одного админа.

**Цель:** Один админ не должен иметь возможности забрать все ресурсы бота (создать тысячи источников).

---

## 🎯 Ключевые файлы

- `core/services/limits.py` — Сервис проверки лимитов
- `core/settings.py` — Настройки лимитов (5 констант)
- `bot/handlers/sources/finalize_handlers.py` — Интеграция проверки
- `tests/test_limits.py` — Тесты (8 тестов)

---

## ⚙️ Лимиты

| Ресурс | Лимит | Обоснование |
|--------|-------|-------------|
| Telegram-каналов | 15 на админа | Личное использование + несколько проектов |
| YouTube-каналов | 10 на админа | YouTube парсинг более ресурсоёмкий |
| **Всего источников** | **25 на админа** | Суммарный лимит (TG + YouTube) |
| Управляемых групп | 5 на админа | 1 личная + 3-4 проекта |
| Топиков в группе | 20 на группу | Достаточно для категоризации |

---

## ⚠️ Важные решения

- **v6.4:** Добавлен сервис `check_source_limit()` — проверка перед добавлением источника
- **v6.4:** Добавлен сервис `check_group_limit()` — проверка перед созданием группы
- **v6.4:** Проверка в `finalize_handlers.py` — перед коммитом в БД
- **v6.4:** Сообщение об ошибке показывает текущие значения и лимиты
- **v6.4:** `message_id` сохраняется после ошибки — меню обновляется, а не создаётся новое

## 🔧 Конфигурация


## 📊 Алгоритм работы

```
1. Пользователь добавляет источник
2. finalize_handlers.py: check_source_limit()
3. Если лимит превышен:
   - Показать ошибку с текущими значениями
   - Сохранить message_id меню
   - Вернуться в главное меню
4. Если лимит не превышен:
   - Продолжить добавление источника
```
