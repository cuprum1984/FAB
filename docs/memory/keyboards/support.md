## ⚙️ Структура клавиатуры

### `get_support_menu_kb()`

**Назначение:** Меню выбора суммы доната.

**Кнопки (2 в ряд):**

| Ряд | Кнопки | Callback |
|-----|--------|----------|
| 1 | 💎 100 ⭐ | `support_100` |
|   | 💎💎 250 ⭐ | `support_250` |
| 2 | 💎💎💎 500 ⭐ | `support_500` |
|   | 👑 2500 ⭐ | `support_2500` |
| 3 | ⚙️ В настройки | `support_settings` |
|   | ◀️ В главное меню | `support_back` |

**Layout:** `builder.adjust(2, 2, 2)`

---

## 📐 Концепция дизайна

### Эмодзи для сумм

| Сумма | Эмодзи | Обоснование |
|-------|--------|-------------|
| 100 | 💎 | Один алмаз |
| 250 | 💎💎 | Два алмаза |
| 500 | 💎💎💎 | Три алмаза |
| 2500 | 👑 | Корона (премиум) |

### Навигация

- **⚙️ В настройки** → возврат в меню настроек
- **◀️ В главное меню** → возврат в главное меню

---

## ⚠️ Важные решения

### v6.5 (2 апреля 2026)

**Решение:** Использовать эмодзи для визуального различения сумм.

**Почему:**
- Быстрое визуальное восприятие
- Интуитивная градация (1 → 2 → 3 → 👑)
- Соответствует концепции Stars (💎)
