# Menu System — Контекст

**Последнее обновление:** 2026-03-30  
**Версия:** 5.7+

---

## 📋 Что это

**Одно сообщение для всей навигации.** Все экраны обновляют одно сообщение вместо отправки новых.

---

## 🎯 Ключевые файлы

- `bot/utils/menu_message.py` — утилиты сообщений
- `bot/keyboards/` — клавиатуры для меню

---

## ⚙️ Константы

| Константа | Значение |
|-----------|----------|
| `MENU_MESSAGE_ID_KEY` | `"_menu_message_id"` |
| `DEFAULT_DELETE_DELAY` | `0` (мгновенно) |

---

## 🔄 Процесс

```
1. update_or_send_menu() → обновить или отправить
2. message_id → сохранить в FSM состоянии
3. При успехе → удалить старое (delay=0), показать новое
```

---

## ⚠️ Важные решения

- **v5.7:** Одно сообщение для всей навигации
- **v5.7:** `message_id` в FSM (глобальный ключ)
- **v5.7:** `DEFAULT_DELETE_DELAY = 0` (мгновенное удаление)
- **v5.7:** `update_or_send_menu()` — основная функция
