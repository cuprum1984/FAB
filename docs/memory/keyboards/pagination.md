# Пагинация — Контекст

**Последнее обновление:** 2026-03-30  
**Версия:** 5.7+

---

## 📋 Что это

Единая система пагинации для всех списков: группы, темы, источники.

---

## 🎯 Ключевые файлы

- `bot/keyboards/admin.py` — `get_groups_inline_kb()`, `get_topics_inline_kb()`
- `bot/keyboards/my_sources.py` — `get_topics_tree_kb()`
- `bot/keyboards/sources.py` — `get_source_list_kb()`

---

## ⚙️ Параметры

| Параметр | Значение |
|----------|----------|
| Элементов на странице | **5** |
| Формат навигации | `[◀️ .] [1/N] [. ▶️]` |
| Заглушка неактивной | Точка `.` |
| Навигация всегда | **Да** (даже 1 страница) |

---

## ⚠️ Важные решения

- **v5.7:** Навигация видна всегда (не скрывать на 1 странице)
- **v5.7:** Заглушка `.` вместо серых кнопок "Назад"/"Вперёд"
- **v5.7:** General топик всегда первый в списке

---

## 📊 Примеры

### 1 страница из 3
```
[◀️ .] [1/3] [▶️ Вперед]
```

### 2 страница из 3
```
[◀️ Назад] [2/3] [▶️ Вперед]
```

### 3 страница из 3
```
[◀️ Назад] [3/3] [. ▶️]
```
