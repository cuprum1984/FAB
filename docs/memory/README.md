**Назначение:** Быстрый контекст по каждому компоненту  
**Последнее обновление:** 30 марта 2026

---

## 📋 Что это

**Memory (память)** — это краткие справки по каждому компоненту проекта.

**Для чего:**
- 🚀 **Быстро вспомнить** через полгода (30 сек вместо 5 мин)
- 🤖 **Контекст для ИИ** при старте новой сессии
- 📝 **История решений** — почему сделано именно так

## 🎯 Формат файла памяти

Каждый файл содержит:

```markdown
# Название — Контекст

**Последнее обновление:** YYYY-MM-DD

## 📋 Что это
1-2 предложения о компоненте

## 🎯 Ключевые файлы
- `path/to/file.py` — описание

## ⚠️ Важные решения
- **vX.Y:** Решение и почему

## 🔗 Связанные документы
- `docs/...` — полная документация
- `docs/09-versions/vX.Y.md` — версия
```

**Размер:** 20-50 строк (читать за 30 сек)

## 🔄 Когда обновлять

| Событие | Действие |
|---------|----------|
| **Изменение кода** | Обновить соответствующий `.md` в `memory/` |
| **Новая фича** | Создать новый файл в `memory/` |
| **Рефакторинг** | Обновить контекст решений |
| **Исправление бага** | Добавить заметку в файл |

## 🚀 Быстрый старт

### Через полгода ты открываешь:

1. **Этот файл** — общая структура
2. **Нужный раздел** — например `keyboards/inline_buttons.md`
3. **Вспомнил за 30 сек** → идёшь в `docs/` за деталями

### ИИ при старте сессии:

1. Читает этот файл
2. Сканирует нужный раздел
3. Понимает контекст без чтения полной документации
