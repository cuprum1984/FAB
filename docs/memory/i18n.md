# 🌐 Локализация (i18n)

**Последнее обновление:** 19 апреля 2026 | **Версия:** 6.9.2

---

## 📋 Контекст

- **Поддерживаемые языки:** `ru` (основной), `en`, `uk`, `be`
- **Файлы:** `locales/{lang}.py` — модули с `MESSAGES` dict
- **Формат:** Python dict с вложенной структурой по компонентам
- **Кодировка:** UTF-8 с BOM-маркером (`# -*- coding: utf-8 -*-`)

---

## 🔑 Структура ключей

```
MESSAGES = {
    "common": {...},           # Общие сообщения (старт, помощь, ошибки)
    "refresh": {...},          # Обновление интерфейса
    "topic_check": {...},      # Проверка тем
    "keyboards": {             # Тексты кнопок
        "main_menu": {...},
        "admin_menu": {...},
        "groups_menu": {...},
        "topics_menu": {...},  # ← добавлено в 6.9.2
        "destinations": {...},
        "overview": {...},     # ← добавлено в 6.9.2
        "sources_list": {...},
        ...
    },
    "admin": {                 # Сообщения админ-панели
        "activ_*": {...},      # Команда /activ
        "plus_*": {...},       # Команда /plus (+ enter_name, validation в 6.9.2)
        "mytopics_*": {...},
        ...
    },
    "sources": {...},          # Добавление/управление источниками
    "topics_auto": {...},      # Авто-уведомления о темах
    "settings": {...},         # Настройки пользователя
    "middleware": {...},       # Сообщения мидлваре
    "legal": {...}             # GDPR / условия использования
}
```

---

## ⚠️ Важные правила

1. **Все языки должны иметь идентичную структуру ключей** — синхронизировать с `ru.py` как эталоном
2. **Форматирование:** Использовать `<b>`, `<i>`, `<code>` для Telegram HTML
3. **Переменные:** `{first_name}`, `{username}`, `{count}` и т.д. — сохранять во всех переводах
4. **Эмодзи:** Сохранять оригинальные эмодзи из ru.py для консистентности UI
5. **Грамматика be.py:** Проверять согласование (мае крыніцы, не маё)

---

## 🔄 Триггеры обновления

| Событие | Действие |
|---------|----------|
| Добавлен новый ключ в ru.py | Добавить переводы в en/uk/be |
| Изменён текст в ru.py | Обновить все языки или пометить для перевода |
| Исправлена грамматика | Применить ко всем языкам при необходимости |
| Новая функциональность | Добавить ключи во все файлы перед релизом |

## 🧪 Проверка перед коммитом

```bash
# 1. Синтаксис всех файлов
python -m py_compile locales/*.py

# 2. Сравнение структур ключей (пример скрипта)
python scripts/check_i18n_keys.py

# 3. Тесты локализации
pytest tests/ -k "i18n or localization" -v
```
