# 📋 Гибридное согласие (Hybrid Consent)

**Версия:** 6.6 (2 апреля 2026)  
**Статус:** ✅ Реализовано  
**GDPR:** Соответствует (implicit consent)

---

## 🎯 Что это

**Гибридное согласие** — механизм получения явного согласия пользователя на обработку персональных данных при первом запуске бота (`/start`).

### Почему "гибридное"

- **Явное действие**: Пользователь нажимает кнопку
- **Implicit consent**: Кнопка = согласие (без отдельной формы)
- **Без новых команд**: Только существующие `/terms`, `/privacy`, `/delete`

---

## 🎮 Хендлеры

### Файл: `bot/handlers/common.py`

| Хендлер | Callback | Описание |
|---------|----------|----------|
| `cmd_start` | — | Проверка согласия при /start |
| `show_consent_request` | — | Показ запроса согласия |
| `on_legal_read_terms` | `legal_read_terms` | Показ документов |
| `on_consent_accept` | `consent_accept` | Запись согласия в БД |
| `on_settings_legal_terms` | `settings_legal_terms` | Документы из настроек |

### Логика `/start`

```
1. Пользователь запускает /start
2. Проверка в БД: consent_given_at
3. Если NULL:
   → show_consent_request()
4. Если TIMESTAMP:
   → Главное меню
```

## 🚀 Как это работает (сценарии)

### Сценарий 1: Новый пользователь

```
1. /start → Регистрация в БД
2. consent_given_at = NULL
3. Показ запроса согласия
4. Нажатие "✅ Понятно"
5. consent_given_at = NOW()
6. Главное меню
```

### Сценарий 2: Повторный запуск

```
1. /start → Проверка БД
2. consent_given_at = TIMESTAMP
3. Сразу главное меню
```

### Сценарий 3: Просмотр документов

```
1. Нажатие "📄 Полные условия"
2. Отправка terms-privacy.md
3. Кнопка "✅ Понятно" под документом
```

### Сценарий 4: Из настроек

```
1. Настройки → "📋 Условия и конфиденциальность"
2. Отправка terms-privacy.md
3. Без кнопки согласия (уже дано)
```

## ⚠️ Важные заметки

### Implicit consent

- Кнопка "✅ Понятно" = явное действие
- Запись в БД фиксирует факт согласия
- Допустимо для простых сервисов

### Если пользователь не нажал "Понятно"

- Бот не работает (ждёт согласия)
- При повторном /start → снова запрос
- Данные не обрабатываются

### Удаление данных

- Команда `/delete` → удаление всех данных
- `consent_given_at` → NULL (фактически удаляется)
- GDPR очистка (30 дней) → удаление неактивных
