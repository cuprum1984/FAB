# 🏗️ Архитектура MyAggryBot

**Версия:** 6.2  
**Последнее обновление:** 30 марта 2026

## 📋 Обзор

MyAggryBot — это распределённая система для агрегации контента из Telegram и YouTube с автоматическим распределением по темам в управляемых группах.

## 🔧 Основные сервисы

### 1. Telegram Bot (`bot/main.py`)

**Назначение:** Обработка команд пользователей, меню, настройки.

**Компоненты:**
- **Handlers** — обработчики команд (`/start`, `/help`, `/settings`, etc.)
- **Keyboards** — inline-клавиатуры
- **Middlewares** — промежуточный слой (i18n, фильтр групп)
- **States** — FSM состояния для диалогов

**Технологии:**
- aiogram 3.13+ (async)
- SQLAlchemy (async)
- FSM (Finite State Machine)

---

### 2. Monitoring Service (`core/services/monitoring/`)

**Назначение:** Парсинг источников (Telegram, YouTube), добавление в очередь.

**Компоненты:**
- **Telegram Monitor** — парсинг Telegram каналов
- **YouTube Monitor** — парсинг YouTube каналов
- **Group Checker** — проверка доступности групп
- **Post Sender** — отправка постов из очереди

**Технологии:**
- APScheduler 3.10+ (планировщик)
- Rate Limiter (Token Bucket)
- Exponential Backoff

---

### 3. Sender Service

**Назначение:** Отправка постов из очереди в темы Telegram.

**Особенности v6.2:**
- **Bulk update** — пакетная отправка
- **Кэш тем** — кэширование информации о темах
- **Изоляция ошибок** — ошибки не влияют на другие потоки

---

### 4. Cleaner Service

**Назначение:** Очистка, проверка групп, статистика.

**Компоненты:**
- **User Cleanup** — GDPR очистка пользователей
- **Subscription Cleanup** — очистка подписок
- **Topic Cleanup** — очистка тем
- **Media Cleanup** — очистка кэша медиа

---

## 📊 Поток данных

```
1. Пользователь добавляет источник
   ↓
2. Источник сохраняется в БД
   ↓
3. Monitoring Service проверяет источник (каждые N минут)
   ↓
4. Новые посты добавляются в очередь (Redis)
   ↓
5. Sender Service забирает из очереди
   ↓
6. Посты отправляются в темы Telegram
   ↓
7. Статистика сохраняется в БД
```

## 🔐 Безопасность

### Rate Limiting

Защита от блокировок Telegram API:

| Параметр | Значение |
|----------|----------|
| Telegram | 10 запросов/сек (ведро 20 токенов) |
| YouTube | 1 запрос/сек (ведро 5 токенов) |
| Глобально | 60 запросов/мин |

**См. подробнее:** [`../../04-services/rate-limiting.md`](../../04-services/rate-limiting.md)

### GDPR

Автоматическая очистка неактивных пользователей:
- Удаление пользователей без активности > N дней
- Каскадное удаление связанных данных
- Логирование операций

**См. подробнее:** [`../../04-services/cleanup-gdpr.md`](../../04-services/cleanup-gdpr.md)
