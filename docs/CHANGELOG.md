## 📝 Как документировать версии

При создании новой версии:

1. **Создать файл** `docs/versions/v{MAJOR}.{MINOR}.md`
2. **Заполнить структуру:**
   - Дата релиза
   - Статус (Актуальная / Стабильная / Устаревшая)
   - Список изменений
   - Затронутые файлы
   - Миграции БД (если есть)
   - Тесты (если добавлены)
   - Известные проблемы

3. **Обновить этот файл** — добавить версию в таблицу
4. **Обновить `docs/overview.md`** — актуализировать версию проекта

4. Обновить docs/CHANGELOG.md
5. Создать git tag v{X}.{Y}
6. Создать релиз на GitHub
