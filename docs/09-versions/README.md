# 📁 Структура документации

Эта папка содержит файлы для каждой версии проекта.

## Формат имени файла

```
v{MAJOR}.{MINOR}.md
```

**Примеры:**
- `v6.2.md` — версия 6.2
- `v5.7.md` — версия 5.7
