## 📋 Обзор

Добавлена поддержка YouTube: парсер и сервис для отслеживания новых видео.

---

## ✨ Новые возможности

- **YouTube Parser** — парсинг YouTube каналов
- **YouTube Service** — сервис для работы с YouTube
- **Интеграция с мониторингом** — автоматическое отслеживание новых видео
