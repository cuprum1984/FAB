# 📦 Версия 6.7 — Copy Message + HTML + Медиа

**Дата:** 6 апреля 2026
**Статус:** ✅ Актуальная

---

## 📋 Изменения

### 1. HTML форматирование постов
- Парсер извлекает HTML вместо `.get_text()` — сохраняются `<b>`, `<i>`, `<a>`, `<u>`, `<code>`, `<pre>`, `<blockquote>`
- Telegram API понимает только ограниченный набор тегов, остальные конвертируются:
  - `<br>`, `<br/>`, `<br />` → `\n`
  - `<p>` → `\n\n`
  - `<i class="emoji">` → разворачивается в текст эмодзи
  - `<tg-emoji>` → разворачивается в текст
  - `<span>` → разворачивается (содержимое сохраняется)
- Все атрибуты `class`, `style`, `onclick` удаляются
- Ссылки проверяются на безопасность (whitelist: http, https, tg, ton)

### 2. Извлечение timestamp
- Парсер извлекает `<time datetime="...">` → Unix timestamp
- Время отображается в сообщении: `14:30`

### 3. Извлечение всех медиа (альбомы)
- Фото: ищутся ВСЕ `.tgme_widget_message_photo_wrap` через `find_all()`
- Видео: `.tgme_widget_message_video`
- GIF/анимация: `.tgme_widget_message_gif`
- Аудио: `audio.tgme_widget_message_voice`
- Документы: `a.tgme_widget_message_document_wrap`
- Превью ссылок: `img.tgme_widget_message_link_image`

### 4. Скачивание и отправка медиа
- Скачивается во временный файл (`tempfile.mkstemp`), не в RAM
- Отправляется через `FSInputFile` (aiogram 3.x)
- После отправки файл удаляется (`os.unlink`)
- Caption обрезается до 1024 символов (лимит Telegram для медиа)
- Поддержка типов: photo, video, video_note, animation, audio, document

### 5. Inline кнопка "📎 Открыть оригинал"
- Вместо текстовой ссылки в caption
- Отключает `disable_web_page_preview`
- При ошибке HTML — fallback на plain text (теги удаляются, не экранируются)

### 6. HTML санитизация
- **Создан:** `core/utils/html_sanitizer.py`
- Whitelist тегов Telegram API
- Проверка URL на безопасность
- Безопасная обрезка HTML (не ломает теги)
- Схлопывание множественных `\n`

### 7. Fallback на plain text
- При ошибке парсинга HTML — теги удаляются через `BeautifulSoup.get_text()`
- **НЕ** используется `html.escape()` (превращает `<b>` в `&lt;b&gt;`)
- Кнопка "Открыть оригинал" сохраняется в plain text fallback

### 8. Убран copy_message
- `copy_message()` не работает для внешних каналов (Bot API ограничение)
- Метод оставлен как заглушка, не вызывается
- Лог больше не засорен предупреждениями

### 9. Убрано уведомление "Ещё N медиафайл(ов)"
- Вместо отдельного сообщения — подпись в caption первого медиа
- Пример: `📎 Ещё 2 медиафайл(ов) в оригинале`

## 🔧 Технические детали

### Архитектура отправки
```
send_to_assignment()
  ↓
┌─────────────────────────────────────────┐
│ ПРИОРИТЕТ 1: HTML текст + медиа + кнопка│
│                                         │
│ Скачивает медиа → FSInputFile →         │
│ send_photo/video/document + caption ≤1024│
│ + InlineKeyboardButton                  │
│                                         │
│ Если успех → return True                │
│ Если ошибка → fallback ↓                │
└─────────────────────────────────────────┘
  ↓
┌─────────────────────────────────────────┐
│ ПРИОРИТЕТ 2: Plain text + кнопка        │
│                                         │
│ BeautifulSoup.get_text() → без тегов    │
│ + InlineKeyboardButton                  │
│                                         │
│ Всегда работает                         │
└─────────────────────────────────────────┘
```

### HTML Whitelist
```python
ALLOWED_TAGS = {
    'b', 'strong',      # Жирный
    'i', 'em',          # Курсив
    'u', 'ins',         # Подчёркнутый
    's', 'strike', 'del',  # Зачёркнутый
    'code',             # Код (inline)
    'pre',              # Блок кода
    'a',                # Ссылки
    'blockquote',       # Цитаты
    'tg-emoji',         # Кастомные эмодзи (разворачивается в текст)
}
```
