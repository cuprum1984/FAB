# 📦 Версия 6.7 — HTML форматирование + Inline кнопка

**Дата:** 6 апреля 2026
**Статус:** ✅ Актуальная (обновлена v6.9)

---

## 📋 Изменения

### 1. HTML форматирование постов
- Парсер извлекает HTML вместо `.get_text()` — сохраняются `<b>`, `<i>`, `<a>`, `<u>`, `<code>`, `<pre>`, `<blockquote>`
- Telegram API понимает только ограниченный набор тегов, остальные конвертируются:
  - `<br>`, `<br/>`, `<br />` → `\n`
  - `<p>` → `\n\n`
  - `<i class="emoji">` → разворачивается в текст эмодзи
  - `<tg-emoji>` → разворачивается в текст
  - `<span>` → разворачивается (содержимое сохраняется)
- Все атрибуты `class`, `style`, `onclick` удаляются
- Ссылки проверяются на безопасность (whitelist: http, https, tg, ton)

### 2. Извлечение timestamp
- Парсер извлекает `<time datetime="...">` → Unix timestamp
- Время отображается в сообщении: `14:30`

### 3. HTML санитизация
- **Создан:** `core/utils/html_sanitizer.py`
- Whitelist тегов Telegram API
- Проверка URL на безопасность
- Безопасная обрезка HTML (не ломает теги)
- Схлопывание множественных `\n`

### 4. Inline кнопка "📢 Название канала"
- Кнопка с названием канала ведёт на оригинал поста
- При ошибке HTML — fallback на plain text (теги удаляются, не экранируются)

### 5. Fallback на plain text
- При ошибке парсинга HTML — теги удаляются через `BeautifulSoup.get_text()`
- **НЕ** используется `html.escape()` (превращает `<b>` в `&lt;b&gt;`)
- Кнопка сохраняется в plain text fallback

## 🔧 Технические детали

### Архитектура отправки (v6.9)
```
send_to_assignment()
  ↓
_format_telegram_post_message() → HTML текст
_get_original_post_keyboard()   → Кнопка "📢 Канал"
_get_link_preview_options()     → Превью (если есть медиа)
  ↓
_send_message_with_retry()
  ↓
bot.send_message(
    text=html_text,
    parse_mode="HTML",
    link_preview_options=LinkPreviewOptions(...),
    reply_markup=keyboard
)
```

### HTML Whitelist
```python
ALLOWED_TAGS = {
    'b', 'strong',      # Жирный
    'i', 'em',          # Курсив
    'u', 'ins',         # Подчёркнутый
    's', 'strike', 'del',  # Зачёркнутый
    'code',             # Код (inline)
    'pre',              # Блок кода
    'a',                # Ссылки
    'blockquote',       # Цитаты
    'tg-emoji',         # Кастомные эмодзи (разворачивается в текст)
}
```
