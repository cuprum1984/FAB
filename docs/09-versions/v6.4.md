## 📋 Обзор

Реализация лимитов Free плана для защиты от злоупотреблений. Ограничивает количество ресурсов (источники, группы, топики) на одного админа.

---

## ✨ Новое

### 1. Сервис лимитов `core/services/limits.py`

**Функции:**
- `check_source_limit()` — проверка лимитов на источники (TG, YouTube, общий)
- `check_group_limit()` — проверка лимита на управляемые группы
- `check_topic_limit()` — проверка лимита на топики в группе

**Код:** ~170 строк

---

### 2. Настройки в `core/settings.py`

**Константы:**
```python
FREE_PLAN_SOURCES_LIMIT: int = 25           # Всего источников
FREE_PLAN_TELEGRAM_LIMIT: int = 15          # TG каналов
FREE_PLAN_YOUTUBE_LIMIT: int = 10           # YouTube каналов
FREE_PLAN_GROUPS_LIMIT: int = 5             # Управляемых групп
FREE_PLAN_TOPICS_PER_GROUP_LIMIT: int = 20  # Топиков в группе
```

---

### 3. Интеграция в `finalize_handlers.py`

**Изменения:**
- Проверка лимита перед добавлением источника
- Сообщение об ошибке с текущими значениями и лимитами
- Сохранение `message_id` меню после ошибки (для обновления)

---
