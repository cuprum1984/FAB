# Версия 6.2

**Дата релиза:** 28 марта 2026  
**Статус:** ✅ Актуальная

---

## 📋 Обзор

Оптимизация PostSender для улучшения производительности отправки постов в Telegram. Внедрены bulk update операции, кэширование тем и изоляция ошибок.

---

## ✨ Новые возможности

- **Bulk update операций** — пакетное обновление вместо поодиночного
- **Кэш тем** — кэширование информации о темах для уменьшения запросов к БД
- **Изоляция ошибок** — ошибки в одном потоке не влияют на другие
