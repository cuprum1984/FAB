# 📦 Версия 6.6 — Гибридное согласие (Hybrid Consent)

**Дата релиза:** 2 апреля 2026  
**Статус:** ✅ Актуальная  
**Предшественник:** [v6.5](v6.5.md) (Telegram Stars)

---

## 📋 Обзор

Версия 6.6 добавляет **гибридное согласие** (Hybrid Consent) — механизм получения явного согласия пользователя на обработку персональных данных при первом запуске бота (`/start`).

Это требование GDPR (General Data Protection Regulation) для работы с персональными данными пользователей из ЕС.

---

## ✨ Новые возможности

### 1. Запрос согласия при `/start`

При первом запуске бот показывает:
- Краткий текст о собираемых данных (5-7 строк)
- Две кнопки:
  - `📄 Полные условия` → отправляет документ `terms-privacy.md`
  - `✅ Понятно, принимаю` → implicit consent, запись в БД

### 2. Кнопка в настройках

В меню настроек добавлена кнопка:
- `📋 Условия и конфиденциальность` → отправляет `terms-privacy.md`

### 3. Хранение согласия

В БД добавлено поле `consent_given_at` в таблице `telegram_accounts`:
- `NULL` — согласие не дано
- `TIMESTAMP` — дата и время дачи согласия

## 📝 Заметки

### Implicit consent

Кнопка "✅ Понятно, принимаю" реализует **implicit consent** (подразумеваемое согласие):
- Пользователь явно нажимает кнопку
- Действие однозначно трактуется как согласие
- Запись в БД фиксирует факт согласия

Это допустимо для простых сервисов и соответствует требованиям GDPR для "явного согласия" (explicit consent).

### GDPR права пользователей

Пользователь имеет право:
1. **Доступ** (ст. 15) → команды `/terms`, `/privacy`
2. **Удаление** (ст. 17) → команда `/delete` или Настройки
3. **Перенос** (ст. 20) → по запросу в поддержку
