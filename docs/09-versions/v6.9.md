# Версия 6.9 — Умное превью постов (LinkPreviewOptions)

**Дата:** 7 апреля 2026
**Приоритет:** 🟡 P1 (улучшение UX)

---

## 📋 Изменения

### Главное
- ✅ **Умное превью** — посты показывают превью прямо в Telegram (LinkPreviewOptions)
- ✅ **Медиа над текстом** — `prefer_large_media=True`, `show_above_text=True`
- ✅ **Кнопка с названием канала** — "📢 TechCrunch" вместо "📎 Открыть оригинал"
- ✅ **Внешние ссылки не перехватывают превью** — явный `url` в `LinkPreviewOptions`
- ✅ **Полное упрощение** — удалено всё лишнее: скачивание медиа, альбомы, fallback приоритеты

### Удалено
| Метод / Код | Причина |
|-------------|---------|
| `_send_media_by_url()` | Скачивание и отправка медиа — не нужно |
| `_download_media()` | Скачивание во временный файл — не нужно |
| `_send_plain_text_to_assignment()` | Fallback без HTML — не нужен |
| `send_media_to_assignment()` | Мёртвый код |
| `send_text_to_assignment()` | Мёртвый код |
| `_send_text_only()` | Мёртвый код |
| `_copy_message_to_topic()` | Мёртвый код |
| `aiohttp`, `tempfile`, `os`, `FSInputFile` | Больше не используются |

### Технические детали
- `post_sender.py`: **~310 строк** (было ~956)
- Один метод: `send_to_assignment()` → `_send_message_with_retry()`
- Никакого скачивания, никаких временных файлов
- Превью работает через `LinkPreviewOptions(url="t.me/...")`

### Как работает превью
Когда `url` явно указан в `LinkPreviewOptions`, Telegram **игнорирует** ссылки в тексте.

**Пример:**
```
Текст: "Apple выпустила iPad Pro. Читать: https://techcrunch.com/article/..."
Превью: Показывает медиа из t.me/techcrunch/123 (не из внешней ссылки)
Ссылка: Остаётся в тексте как есть
```

## ⚠️ Известные ограничения

1. **Альбомы** — `send_media_group` не поддерживает `link_preview_options`. Превью не показывается для альбомов (медиа и так видно).
2. **Посты без медиа** — превью отключено (`is_disabled=True`)
3. **Нет ссылки на пост** — превью отключено
