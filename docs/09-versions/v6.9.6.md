# 📦 Версия 6.9.6 — Локализация кнопки "Поддержать автора"

**Дата релиза:** 19 апреля 2026  
**Статус:** ✅ Актуальная  
**Предшественник:** [6.9.5](v6.9.5.md)

---

## 🎯 Цель

Исправить отсутствие локализации кнопки "💎 Поддержать автора" в меню настроек (`/settings`).

---

## 📋 Изменения

### 🔧 Код

#### `bot/keyboards/settings.py`
```diff
- text="💎 Поддержать автора",
+ text=get_text(['keyboards', 'settings_menu', 'support']),
```

### 🌐 Локализация

Добавлен новый ключ `keyboards.settings_menu.support` во все языковые файлы:

| Файл | Значение |
|------|----------|
| `locales/ru.py` | `💎 Поддержать автора` |
| `locales/en.py` | `💎 Support the Author` |
| `locales/uk.py` | `💎 Підтримати автора` |
| `locales/be.py` | `💎 Падтрымаць аўтара` |

---

## 🧪 Тестирование

### Проверка локализации:
1. Запустите бота: `python bot.py`
2. Смените язык: `/settings` → `🌐 Язык` → выберите язык
3. Откройте меню настроек: `/settings`
4. ✅ Кнопка поддержки должна отображаться на выбранном языке

### Проверка функционала:
1. Нажмите кнопку поддержки
2. ✅ Меню поддержки открывается с корректным текстом
3. ✅ Все навигационные кнопки работают
4. ✅ При выборе суммы создаётся invoice с локализованным title/description

## 📝 Примечания

- Кнопки с суммами (`💎 100 ⭐`) намеренно оставлены без перевода текста, так как суммы и символ ⭐ универсальны
- Эмодзи 💎 понятны во всех языках и не требуют локализации
- При необходимости можно добавить `description` к кнопкам с пояснением в локальной валюте
