# Версия 1.0

**Дата релиза:** 05 февраля 2026  
**Статус:** ✅ Стабильная

---

## 📋 Обзор

Базовая версия бота. Основные возможности:

- Регистрация пользователей
- Управление группами
- Добавление источников
- Базовое меню

---

## ✨ Новые возможности

- **Telegram Bot** — бот на aiogram 3.x
- **База данных** — PostgreSQL + SQLAlchemy
- **Локализация** — базовая поддержка ru/en
- **Меню** — главное меню с кнопками
