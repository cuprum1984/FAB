# Версия 6.9.8 - Очистка "Обзора", фиксы импортов и обновление MCP-сервера (v3.0)

**Дата:** 20 апреля 2026  
**Статус:** Актуальная  
**Автор:** AI-ассистент (MCP CLI)

## 📋 Обзор
Финальное удаление функционала "Обзор", исправление критических ошибок импорта/сигнатур, перевод MCP-сервера в полноценный CLI-режим (v3.0) и синхронизация конфигурационных файлов.

## 🆕 Новые возможности
- **MCP Server v3.0 CLI-READY:** Добавлены инструменты `search_text` (поиск regex), `run_shell` (безопасный запуск команд), `write_file` (создание/перезапись).
- **Multi-Root Support:** Сервер принимает несколько разрешённых директорий через аргументы командной строки (`ALLOWED_ROOTS`).
- **No-Backup Mode:** Полностью удалена логика создания `.bak` файлов для ускорения и упрощения работы.

## ⚙️ Изменения
- Удалены все упоминания "Обзора": кнопка, хендлеры (`menu_overview`, `overview_page:`), клавиатура `get_overview_kb`, FSM-состояние `Overview`.
- Функция `format_sources_overview_page` переименована в `format_sources_page` (убрана семантическая привязка к удалённому разделу).
- Обновлён `settings.json` до v1.2: очищены "битые" пути с пробелами в `permissions`, добавлены `ignore_patterns` и `allowed_commands_prefixes`.
- Обновлён `GUIDELINES.md`: отражены новые инструменты CLI, убраны упоминания авто-бэкапов, добавлен шаг поиска в workflow.
- Обновлены файлы памяти (`docs/memory/`) с учётом изменений в роутинге и клавиатурах.

## 🐛 Исправления
- `ImportError: cannot import name 'get_overview_kb'` → удалены все зависимые импорты и заменены на актуальные (`get_topics_tree_kb`).
- `UnboundLocalError` в `on_back_pressed` → добавлен отсутствующий параметр `session: AsyncSession` в сигнатуру хендлера.
- Конфликт имён в `my_server.py` → переменная `create_backup` (bool) переименована в `should_backup`, чтобы не перекрывать функцию.

## ⚠️ Известные проблемы
- Файлы локализации `en.py`, `uk.py`, `be.py` могут содержать неиспользуемые ключи `overview`. Не критично, безопасно удалить при следующем обновлении словарей.
- При использовании `edit_file` отсутствует автоматический откат. Рекомендуется использовать `run_shell git status` или ручные копии перед массовыми правками.
