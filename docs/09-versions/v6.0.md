## 📋 Обзор

Крупный рефакторинг архитектуры: разделение модулей keyboards и messages на отдельные компоненты. Улучшена структура проекта для лучшей поддерживаемости.

---

## ✨ Новые возможности

- **Модульная структура клавиатур** — разделение по категориям
- **Разделение сообщений** — выделение логики сообщений в отдельный модуль

---

## 🔧 Изменения

| Файл | Изменения |
|------|-----------|
| `bot/keyboards/` | Создан новый модуль с подкатегориями |
| `bot/keyboards.py` | Оставлен для обратной совместимости (shim) |
| `bot/messages/` | Новый модуль для работы с сообщениями |

### Структура keyboards/

```
bot/keyboards/
├── __init__.py
├── main_menu.py       # Главное меню
├── my_sources.py      # Клавиатуры источников
├── admin.py           # Админ-панель
├── settings.py        # Настройки
├── sources.py         # Добавление источников
└── destinations.py    # Выбор назначений
```
