## 📋 Обзор

Масштабирование системы мониторинга: внедрение Semaphore для ограничения параллелизма, оптимизация N+1 запросов, защита от простоя и TaskDispatcher.

---

## ✨ Новые возможности

- **Semaphore Monitoring** — ограничение количества одновременных задач парсинга
- **N+1 оптимизация** — уменьшение количества запросов к БД
- **Защита от простоя** — механизм предотвращения блокировок
- **TaskDispatcher** — диспетчер задач для управления очередями
