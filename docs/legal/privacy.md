## 1. Какие данные собираются

### 1.1. Персональные данные пользователей

| Категория | Данные | Источник | Цель сбора |
|-----------|--------|----------|------------|
| **Идентификатор** | Telegram Account ID (число) | Telegram API | Идентификация пользователя |
| **Username** | @username (строка) | Telegram API | Отображение в интерфейсе |
| **Имя** | First Name, Last Name | Telegram API | Персонализация |
| **Язык** | Language Code (ru/en/uk/be) | Telegram API | Локализация интерфейса |
| **Активность** | Last Activity Timestamp | Бот | Статистика, GDPR очистка |
| **Согласие** | Consent Given At, Withdrawn At | Бот | Юридическое основание |

### 1.2. Данные групп и каналов

| Категория | Данные | Источник | Цель сбора |
|-----------|--------|----------|------------|
| **Группы** | Chat ID, Title, Type | Telegram API | Управление группами |
| **Темы** | Topic ID, Name, Thread ID | Telegram API | Распределение контента |
| **Источники** | Username, URL, Type | Пользователь | Парсинг контента |
| **Подписки** | Group ID, Source ID | Пользователь | Маршрутизация контента |

### 1.3. Технические данные

| Категория | Данные | Хранение | Срок хранения |
|-----------|--------|----------|---------------|
| **Логи** | Timestamp, User ID, Action | Файлы логов | 30 дней |
| **Кэш** | Media File ID, Post ID | Redis | До 24 часов |
| **Сессии** | FSM State, Data | Redis | До 5 минут (TTL) |
| **Медиа** | File ID, Expires At | PostgreSQL | До 30 дней |

### 1.4. Данные, которые НЕ собираются

❌ Бот **НЕ** собирает следующие данные:
- Номер телефона пользователя
- Email адрес
- Геолокация
- IP адрес
- Платёжные данные (обрабатываются Telegram)
- Пароли или токены доступа
- Личные сообщения пользователя

## 2. Как данные используются

### 2.1. Основные цели обработки

| Цель | Правовое основание | Данные |
|------|-------------------|--------|
| Предоставление услуг Бота | Исполнение договора (ст. 6(1)(b) GDPR) | Все данные |
| Улучшение функционала | Законный интерес (ст. 6(1)(f) GDPR) | Анонимизированные данные |
| GDPR-очистка | Законная обязанность (ст. 6(1)(c) GDPR) | Дата активности |
| Поддержка пользователей | Законный интерес (ст. 6(1)(f) GDPR) | User ID, Username |
| Статистика и аналитика | Законный интерес (ст. 6(1)(f) GDPR) | Анонимизированные данные |

### 2.2. Автоматизированная обработка

Бот автоматически обрабатывает данные для:

| Процесс | Описание | Частота |
|---------|----------|---------|
| **Парсинг источников** | Проверка новых постов в Telegram/YouTube | Каждые 5-30 мин |
| **Публикация контента** | Отправка постов в темы групп | По расписанию |
| **GDPR-очистка** | Удаление неактивных пользователей | Раз в сутки |
| **Очистка кэша** | Удаление старого кэша медиа | Раз в сутки |
| **Rate Limiting** | Ограничение запросов к API | В реальном времени |

### 2.3. Профилирование

❌ Бот **НЕ** осуществляет профилирование пользователей:
- Нет анализа поведения для принятия автоматических решений
- Нет персонализированной рекламы
- Нет оценки предпочтений

## 3. Как данные хранятся

### 3.1. Хранение данных

| Система | Тип данных | Расположение | Защита |
|---------|------------|--------------|--------|
| **PostgreSQL** | Пользователи, группы, источники | Сервер (EU/Россия) | SSL/TLS, доступ по паролю |
| **Redis** | Кэш, сессии, очереди | Сервер (EU/Россия) | Доступ по паролю |
| **Файлы логов** | Логи операций | Сервер | Ограниченный доступ |

### 3.2. Срок хранения данных

| Категория | Срок хранения | Критерий удаления |
|-----------|---------------|-------------------|
| **Активные пользователи** | Бессрочно | Пока пользователь активен |
| **Неактивные пользователи** | 30 дней без активности | GDPR-очистка |
| **Заблокированные пользователи** | 30 дней после блокировки | GDPR-очистка |
| **Кэш медиа** | 24 часа | Автоматическая очистка |
| **Логи** | 30 дней | Ротация логов |
| **Отзыв согласия** | 3 года | Юридический срок |

### 3.3. Резервное копирование

- **Частота:** Ежедневно
- **Хранение:** 7 дней
- **Шифрование:** Да (AES-256)
- **Расположение:** Отдельный сервер

## 6. Очистка данных (GDPR compliance)

### 6.1. Автоматическая GDPR-очистка

Бот автоматически удаляет данные пользователей при соблюдении условий:

| Условие | Критерий | Действие |
|---------|----------|----------|
| **Блокировка бота** | `is_bot_blocked = True` + 30 дней без активности | Удаление аккаунта и всех данных |
| **Неактивность группы** | `is_bot_active_in_group = False` + 90 дней | Удаление группы и подписок |
| **Истечение кэша** | `expires_at < NOW()` | Удаление кэша медиа |
| **Отзыв согласия** | `consent_withdrawn_at IS NOT NULL` | Немедленная очистка |

### 6.2. Процесс очистки

```
[Обнаружение условия]
  ↓
[Проверка критериев]
  ↓
[Логирование операции]
  ↓
[Каскадное удаление данных]
  ├─→ UserPreferences
  ├─→ UserChannelSubscription
  ├─→ SourceSubscription
  ├─→ TopicSourceAssignment
  └─→ TelegramAccount
  ↓
[Очистка Redis кэша]
  ↓
[Подтверждение удаления]
```

### 6.3. Каскадное удаление

При удалении пользователя автоматически удаляются:

| Таблица | Связь | Каскад |
|---------|-------|--------|
| `user_preferences` | user_id | CASCADE |
| `user_channel_subscriptions` | user_id | CASCADE |
| `source_subscriptions` | added_by_telegram_account_id | SET NULL |
| `group_topics` | created_by_telegram_account_id | SET NULL |
| `cached_media` | (нет прямой связи) | Очистка по TTL |

### 6.4. Удаление по запросу пользователя

Пользователь может удалить свои данные в любой момент:

**Способ 1: Через Бота**
```
Настройки → Удалить мои данные → Подтвердить
```

**Способ 2: Через команду**
```
/delete → Подтвердить
```

**Результат:**
- ✅ Все персональные данные удалены из БД
- ✅ Кэш очищен в Redis
- ✅ Аккаунт помечен как «Deleted User»
- ✅ Логи анонимизированы
