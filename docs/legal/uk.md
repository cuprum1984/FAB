# Умови використання та Політика конфіденційності MyAggryBot

## 👋 Привіт!
Використовуючи бота MyAggryBot, ви погоджуєтеся з наступними правилами:

## 📋 Що робить бот
MyAggryBot — це агрегатор контенту для Telegram:
- 📡 Парсить Telegram-канали та YouTube
- 📤 Автоматично публікує пости у ваші групи

## ✅ Що ви підтверджуєте
1. **Вам є 16 років**
2. **Ви прочитали ці умови**
3. **Ви згодні на обробку даних** (див. нижче)

## 📊 Які дані ми збираємо
| Дані | Навіщо |
|------|--------|
| Telegram ID | Щоб знати, хто ви |
| Username (@name) | Для відображення в інтерфейсі |
| Ваше ім'я (з Telegram) | Для персоналізації |
| Мова (ru/en/uk/be) | Щоб спілкуватися вашою мовою |
| Дата активності | Для GDPR-очищення (видалення неактивних) |

**Ми НЕ збираємо:**
- ❌ Номер телефону
- ❌ Email
- ❌ Геолокацію
- ❌ Платіжні дані (їх обробляє Telegram)

## 🗄️ Як ми зберігаємо дані
- **База даних:** PostgreSQL
- **Кеш:** Redis (до 24 годин)
- **Логи:** 30 днів
- **Видалення:** Через 30 днів без активності → автоматичне очищення

## 🎯 Як ми використовуємо дані
- Для роботи бота (парсинг, публікація постів)
- Для GDPR-очищення (видалення неактивних користувачів)
- Для статистики (в анонімному вигляді)
**Ми НЕ продаємо і НЕ передаємо дані третім особам** (окрім Telegram API для роботи бота).

## 🆓 Ліміти безкоштовного тарифу
- 25 джерел всього (15 Telegram + 10 YouTube)
- 5 керованих груп
- 20 топиків в одній групі

## 💎 Пожертви (Telegram Stars)
- Суми: 100, 250, 500, 2500 ⭐

## 🚫 Блокування джерел на прохання автора
Якщо ви є автором контенту (Telegram-канал або YouTube-канал) і не хочете, щоб MyAggryBot парсив ваш контент:

1. **Зверніться до розробника** — напишіть у підтримку @
2. **Вкажіть ваш канал** — username або посилання
3. **Ми заблокуємо джерело** — усі підписки та призначення будуть видалені

Після блокування:
- ⛔ Канал виключається з парсингу назавжди
- 🗑️ Усі підписки та призначення видаляються
- 🔒 При спробі додати канал знову — користувач отримає сповіщення про блокування

**Ми поважаємо права авторів контенту та оперативно реагуємо на звернення.**

## 🚫 Що не можна робити
- Використовувати бота в незаконних цілях
- Додавати канали з контентом 18+, насильством, спамом
- Намагатися обходити ліміти
- Використовувати вразливості бота
**При порушенні:** блокування без попередження

## 🔒 Ваші права (GDPR)
Якщо ви з ЄС, ви маєте право:
- ✅ Отримати копію своїх даних
- ✅ Виправити неточні дані
- ✅ Видалити всі дані (меню налаштувань)

## 📞 Контакти
**Підтримка:** @

## ⚠️ Обмеження відповідальності
Бот надається «як є». Ми не несемо відповідальності за:
- Збитки від використання бота
- Контент у джерелах (TG-канали, YouTube)
- Збої в роботі API Telegram
- Дії третіх осіб (злам не з нашої вини)

## 🔄 Зміни умов
Ми можемо змінювати ці умови. Нова версія публікується в боті. Продовження використання = прийняття змін.
