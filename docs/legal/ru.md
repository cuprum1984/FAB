# Условия использования и Политика конфиденциальности MyAggryBot

## 👋 Привет!
Используя бота MyAggryBot, вы соглашаетесь со следующими правилами:

## 📋 Что делает бот
MyAggryBot — это агрегатор контента для Telegram:
- 📡 Парсит Telegram-каналы и YouTube
- 📤 Автоматически публикует посты в ваши группы

## ✅ Что вы подтверждаете
1. **Вам есть 16 лет**
2. **Вы прочитали эти условия**
3. **Вы согласны на обработку данных** (см. ниже)

## 📊 Какие данные мы собираем
| Данные | Зачем |
|--------|-------|
| Telegram ID | Чтобы знать, кто вы |
| Username (@name) | Для отображения в интерфейсе |
| Ваше имя (из Telegram) | Для персонализации |
| Язык (ru/en/uk/be) | Чтобы говорить на вашем языке |
| Дата активности | Для GDPR-очистки (удаление неактивных) |

**Мы НЕ собираем:**
- ❌ Номер телефона
- ❌ Email
- ❌ Геолокацию
- ❌ Платёжные данные (их обрабатывает Telegram)

## 🗄️ Как мы храним данные
- **База данных:** PostgreSQL
- **Кэш:** Redis (до 24 часов)
- **Логи:** 30 дней
- **Удаление:** Через 30 дней без активности → автоматическая очистка

## 🎯 Как мы используем данные
- Для работы бота (парсинг, публикация постов)
- Для GDPR-очистки (удаление неактивных пользователей)
- Для статистики (в анонимном виде)
**Мы НЕ продаём и НЕ передаём данные третьим лицам** (кроме Telegram API для работы бота).


## 🆓 Лимиты бесплатного тарифа
- 25 источников всего (15 Telegram + 10 YouTube)
- 5 управляемых групп
- 20 топиков в одной группе


## 💎 Пожертвования (Telegram Stars)
- Суммы: 100, 250, 500, 2500 ⭐

## 🚫 Блокировка источников по просьбе автора
Если вы являетесь автором контента (Telegram-канал или YouTube-канал) и не хотите, чтобы MyAggryBot парсил ваш контент:

1. **Обратитесь к разработчику** — напишите в поддержку @
2. **Укажите ваш канал** — username или ссылку
3. **Мы заблокируем источник** — все подписки и назначения будут удалены

После блокировки:
- ⛔ Канал исключается из парсинга навсегда
- 🗑️ Все подписки и назначения удаляются
- 🔒 При попытке добавить канал снова — пользователь получит уведомление о блокировке

**Мы уважаем права авторов контента и оперативно реагируем на обращения.**

## 🚫 Что нельзя делать
- Использовать бота в незаконных целях
- Добавлять каналы с контентом 18+, насилием, спамом
- Пытаться обходить лимиты
- Использовать уязвимости бота
**При нарушении:** блокировка без предупреждения


## 🔒 Ваши права (GDPR)
Если вы из ЕС, вы имеете право:
- ✅ Получить копию своих данных
- ✅ Исправить неточные данные
- ✅ Удалить все данные (меню настроек)
