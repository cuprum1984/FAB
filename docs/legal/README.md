## 🔒 Гибридное согласие (Hybrid Consent)

**Версия:** 6.6 (2 апреля 2026)

### Что это

**Гибридное согласие** — это механизм получения явного согласия пользователя на обработку персональных данных при первом запуске бота (`/start`).

### Как работает

```
1. Пользователь запускает /start
2. Бот проверяет поле consent_given_at в БД
3. Если consent_given_at = NULL:
   → Показывает краткий текст (5-7 строк)
   → 2 кнопки: [📄 Полные условия] [✅ Понятно, принимаю]
4. При нажатии [✅ Понятно]:
   → Запись consent_given_at = NOW() в БД
   → Показ главного меню
```

### Кнопки

| Кнопка | Действие |
|--------|----------|
| `📄 Полные условия` | Отправляет `terms-privacy.md` |
| `✅ Понятно, принимаю` | Implicit consent, запись в БД |
| `📋 Условия и конфиденциальность` (в настройках) | Отправляет `terms-privacy.md` |

### База данных

**Таблица:** `telegram_accounts`

| Поле | Тип | Описание |
|------|-----|----------|
| `consent_given_at` | DateTime | Дата дачи согласия (NULL = не дано) |

### Хендлеры

| Хендлер | Callback | Описание |
|---------|----------|----------|
| `cmd_start` | — | Проверка согласия при /start |
| `on_legal_read_terms` | `legal_read_terms` | Показ документов |
| `on_consent_accept` | `consent_accept` | Запись согласия в БД |
| `on_settings_legal_terms` | `settings_legal_terms` | Документы из настроек |

## 🎯 Ключевые положения

### Условия использования

| Положение | Описание |
|-----------|----------|
| **Возраст** | 16+ лет |
| **Согласие** | Явное, при /start (кнопка) |
| **Лимиты Free** | 25 источников, 5 групп, 20 топиков |
| **Донаты** | Telegram Stars (100, 250, 500, 2500 ⭐) |
| **Возврат** | 14 дней (за вычетом комиссии 30%) |
| **Блокировка** | Без уведомления, при нарушении |
| **Юрисдикция** | Российская Федерация |

### Политика конфиденциальности

| Положение | Описание |
|-----------|----------|
| **Данные** | User ID, Username, Имя, Язык, Активность |
| **Хранение** | PostgreSQL + Redis (EU/Россия) |
| **Срок** | 30 дней без активности → GDPR очистка |
| **Права GDPR** | Доступ, Исправление, Удаление, Перенос |
| **Удаление** | Команда `/delete` или Настройки |
| **Безопасность** | SSL/TLS, шифрование, бэкапы |
| **Передача** | Telegram, YouTube, хостинг |
