# Условия использования MyAggryBot

**Версия:** 1.0  
**Дата вступления в силу:** 2 апреля 2026  
**Последнее обновление:** 2 апреля 2026

---

## 1. Общие положения

1.1. Настоящие Условия использования (далее — «Условия») регулируют порядок использования бота MyAggryBot (далее — «Бот») в мессенджере Telegram.

1.2. Бот предназначен для агрегации контента из различных источников (Telegram-каналы, YouTube) и автоматического распределения по темам в управляемых группах.

1.3. Используя Бота, вы подтверждаете, что:
- Достигли возраста 16 лет
- Ознакомились с настоящими Условиями
- Принимаете все положения Условий без исключений
- Даёте согласие на обработку персональных данных в соответствии с Политикой конфиденциальности

1.4. Если вы не согласны с настоящими Условиями, пожалуйста, не используйте Бота.

---

## 2. Описание функционала

2.1. **Основные возможности Бота:**

| Функция | Описание |
|---------|----------|
| 📡 Парсинг Telegram | Мониторинг публичных Telegram-каналов на наличие новых постов |
| 📺 Парсинг YouTube | Отслеживание новых видео на YouTube-каналах |
| 📤 Автопубликация | Автоматическая публикация контента в темы управляемых групп |
| 🎯 Распределение | Маршрутизация контента по назначениям (группы/топики) |
| 💎 Донаты | Приём добровольных пожертвований через Telegram Stars |

2.2. **Технические характеристики:**

- Интервал проверки Telegram-каналов: 5 минут
- Интервал проверки YouTube-каналов: 30 минут
- Rate Limiting: защита от блокировок API (Token Bucket алгоритм)
- GDPR-очистка: автоматическое удаление неактивных пользователей через 30 дней

2.3. Бот предоставляет бесплатный тарифный план (Free) с ограничениями:
- Максимум 25 источников (15 Telegram + 10 YouTube)
- Максимум 5 управляемых групп
- Максимум 20 топиков в одной группе

## 3. Регистрация и согласие

3.1. При первом запуске Бота (`/start`) пользователь должен дать явное согласие с настоящими Условиями и Политикой конфиденциальности.

3.2. Согласие фиксируется путём нажатия кнопки «✅ Я согласен с Условиями и Политикой».

3.3. Факт согласия сохраняется в базе данных с указанием даты и времени (`consent_given_at`).

3.4. Без подтверждения согласия доступ к функционалу Бота не предоставляется.

3.5. Пользователь может в любой момент отозвать согласие через Настройки → Удалить мои данные.

## 6. Обязанности пользователя

6.1. Пользователь обязуется:

- Не использовать Бота в незаконных целях
- Не нарушать авторские права при добавлении источников
- Не добавлять приватные каналы без согласия владельцев
- Не использовать Бота для спама или массовых рассылок
- Не пытаться обходить установленные лимиты
- Не использовать уязвимости Бота в корыстных целях

6.2. **Запрещённый контент:**

Запрещается добавлять источники, распространяющие:
- Контент для взрослых (18+)
- Призывы к насилию или экстремизму
- Персональные данные третьих лиц
- Вредоносное ПО или вирусы

6.3. При обнаружении нарушений Администрация вправе:
- Заблокировать доступ пользователя к Боту
- Удалить нарушающие источники

## 7. Ограничения ответственности

7.1. **Бот предоставляется «как есть» (as is):**

Бот предоставляется без каких-либо явных или подразумеваемых гарантий.

7.2. **Ограничение ответственности:**

Администрация не несёт ответственности за:
- Прямые или косвенные убытки от использования Бота
- Утрату данных или контента
- Простои в работе Бота (технические работы, сбои API Telegram)
- Контент, публикуемый в источниках (Telegram-каналы, YouTube)
- Действия третьих лиц (взлом, утечки данных не по вине Администрации)

7.3. **Точность данных:**

Администрация не гарантирует:
- Полноту или актуальность публикуемого контента
- Доступность источников в любой момент времени
- Корректность парсинга всех типов контента

7.4. **Внешние сервисы:**

Бот использует сторонние сервисы:
- Telegram API (регулируется Telegram Terms of Service)
- YouTube API (регулируется YouTube Terms of Service)
- PostgreSQL (база данных)
- Redis (кэширование)

Администрация не контролирует работу этих сервисов.
