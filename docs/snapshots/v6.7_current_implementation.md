## 📋 Что реализовано

### 1. Парсер Telegram (`core/parser/telegram_posts.py`)

#### Извлечение текста
- HTML вместо `.get_text()` — сохраняются `<b>`, `<i>`, `<a>`, `<u>`, `<code>`, `<pre>`, `<blockquote>`
- Исключение блока цитат (reply): `post_clone.find_all(class_='tgme_widget_message_reply').decompose()`
- Санитизация через `html_sanitizer.py`

#### Извлечение медиа
- **Фото (альбомы):** `find_all('a.tgme_widget_message_photo_wrap')` — ВСЕ фото, не только первое
- **Видео:** `video.tgme_widget_message_video`
- **Видео-кружок:** `video.tgme_widget_message_round_video`
- **GIF/анимация:** `a.tgme_widget_message_gif` → `data-video-src`
- **Аудио:** `audio.tgme_widget_message_voice`
- **Документ:** `a.tgme_widget_message_document_wrap`
- **Превью ссылок:** `img.tgme_widget_message_link_image`

#### Извлечение timestamp
- `<time datetime="...">` → `datetime.fromisoformat()` → Unix timestamp

#### Возвращаемая структура
```python
{
    'post_id': '12345',
    'text': '<b>Жирный</b> текст...',  # HTML
    'media': [
        {'type': 'photo', 'url': 'https://cdn4.telesco.pe/file/...'},
        {'type': 'video', 'url': 'https://cdn4.telesco.pe/file/...mp4'},
    ],
    'url': 'https://t.me/username/12345',
    'timestamp': 1712345678  # Unix timestamp
}
```

### 2. HTML Санитизатор (`core/utils/html_sanitizer.py`)

#### Whitelist тегов
```python
ALLOWED_TAGS = {
    'b', 'strong', 'i', 'em', 'u', 'ins',
    's', 'strike', 'del', 'code', 'pre',
    'a', 'blockquote', 'tg-emoji'
}
```

#### Конвертации
- `<br>`, `<br/>`, `<br />` → `\n`
- `<p>` → `\n\n` + unwrap
- `<i class="emoji"><b>🚢</b></i>` → `🚢` (разворачивается)
- `<tg-emoji emoji-id="...">` → разворачивается в текст
- `<span>` → unwrap

#### Удаление атрибутов
- У ВСЕХ тегов: `class`, `style`, `dir`
- У `<a>`: `target`, `rel`, `onclick`, `onmouseover`
- Остаётся только `href` для ссылок

#### Проверка URL
- Разрешённые схемы: `http`, `https`, `tg`, `ton`
- Блокируются: `javascript:`, `data:`, `vbscript:`

#### Обрезка
- `max_length=4000` по умолчанию
- Безопасная обрезка HTML (не ломает теги)
- Множественные `\n\n\n` схлопываются до `\n\n`

### 3. PostSender (`core/services/monitoring/post_sender.py`)

#### Приоритеты отправки
```
send_to_assignment()
  ↓
┌─────────────────────────────────────────┐
│ ПРИОРИТЕТ 1: HTML + медиа + кнопка      │
│                                         │
│ Если медиа нашлось → скачиваем → FSInputFile │
│ caption ≤ 1024 символов                  │
│ InlineKeyboardButton "📎 Открыть оригинал" │
│                                         │
│ Если успех → return True                │
│ Если ошибка → fallback ↓                │
└─────────────────────────────────────────┘
  ↓
┌─────────────────────────────────────────┐
│ ПРИОРИТЕТ 2: Plain text + кнопка        │
│                                         │
│ BeautifulSoup.get_text() → без тегов    │
│ + InlineKeyboardButton                  │
└─────────────────────────────────────────┘
```

#### Скачивание медиа
```python
# Скачиваем чанками по 64KB
fd, temp_path = tempfile.mkstemp(suffix=ext, prefix='aggry_media_')
with open(temp_path, 'wb') as f:
    async for chunk in resp.content.iter_chunked(64 * 1024):
        f.write(chunk)

# Отправляем через FSInputFile (aiogram 3.x)
await bot.send_photo(chat_id, photo=FSInputFile(temp_path), ...)

# Удаляем (finally)
os.unlink(temp_path)
```

#### Распознавание типов медиа
| Тип | Bot метод |
|-----|-----------|
| `photo` | `bot.send_photo()` |
| `video` | `bot.send_video()` |
| `video_note` | `bot.send_video_note()` |
| `animation` | `bot.send_animation()` |
| `audio` | `bot.send_audio()` |
| `document` | `bot.send_document()` |

#### Лимиты
- **Caption для медиа:** ≤ 1024 символа
- **Текст сообщения:** ≤ 4096 символов
- **Таймаут скачивания:** 30 сек
- **Размер файла:** без лимита (пока)

#### Fallback на plain text
- `html_to_plain_text()` — удаляет теги через BeautifulSoup.get_text()
- НЕ `html.escape()` (превращает `<b>` в `&lt;b&gt;`)

## ⚠️ Известные проблемы

| # | Проблема | Причина |
|---|----------|---------|
| 1 | **Медиа не всегда находится** | Видео грузится на CDN медленно, парсер ловит раньше |
| 2 | **Большое видео (>50 МБ)** | Может не успеть загрузиться, таймаут 30 сек |
| 3 | **Альбомы: только 1 фото** | Отправляется первое, остальные не отправляются |
| 4 | **Военные каналы** | Плохой интернет у авторов → медиа долго грузится |
| 5 | **Каналы стали приватными** | `t.me/s/` не обновляется (@robert_magyar) |
